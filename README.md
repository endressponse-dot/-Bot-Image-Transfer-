A bot that performs a series of actions: extracting only images from the content inside branching threads, forwarding them to a separately prepared channel designated for continuous image sharing, and deleting them after 7 days. Since there seemed to be no existing bot that monitors multiple scattered threads and periodically fetches only specific information, I created this. It specializes in images because the goal is image forwarding.

枝分かれするスレッド内部の内容から画像のみを抜き出し、別に用意した画像垂れ流し用のチャンネルに転送し、7日後に削除するまでの一連の動作を行うBOT。  複数の乱立するスレッドを監視して一部情報のみを定期的に取得するやつはないらしいので作成。画像転送がしたいので画像特化。
